# Data

Only this file and one metadata file per UEA dataset are tracked; every dataset is downloaded or generated by the
commands below.

## UEA classification

```bash
python experiments/uea/eigenworms/download_eigenworms.py   # the UEA archive, into data/eigenworms/raw/
python experiments/uea/make_walker_splits.py --all         # Walker's per-seed splits of the six datasets
```

`make_walker_splits.py` reproduces the partitions of log-neural-cdes exactly (its JAX key chain, seeds 2345 to 6789)
and writes `data/<stem>/splits/<stem>_seed{0..4}.npz`, with `<stem>` one of `eigenworms_walker`,
`ethanolconcentration_walker`, `heartbeat_walker`, `motorimagery_walker`, `selfregulationscp1_walker` and
`selfregulationscp2_walker`. The loader scales each split to [-1, 1].

## Formal languages

Generated on the fly by the task code in `experiments/fl/tasks/`, vendored from
[structured-linear-cdes](https://github.com/Benjamin-Walker/structured-linear-cdes) at 243cb30 (MIT).

## Synthetic regression

```bash
python experiments/sde/sde_a/generate_sde_a.py --seed 0                            # coupled oscillator
python experiments/sde/sde_d/generate_sde_d.py --a_true EWS --seed 0 --gpu 0       # expressivity (EWS, EFM or Sig target)
JAX_PLATFORMS=cpu python experiments/sde/oscillatory_kernel/generate.py --seed 0   # oscillatory kernel
```

The oscillator and the expressivity study use data seeds 0 to 9 (`sde_results/replicate.sh` generates any missing
file), the oscillatory kernel data seed 0.

## Weather

`data/weather/WTH.csv` is the Informer2020 weather file (35,064 hourly rows of 12 channels, 2010 to 2013) from the
Informer2020 data release, sha256 prefix `153fead3ea2a83dc`. `experiments/weather/data.py` reads it as it is.

## PPG-DaLiA

`data/ppg/processed_walker/{X,y}_{train,val,test}.npy` are the PPG-DaLiA windows as LinOSS and D-LinOSS use them: the
output of `data_dir/process_ppg.py` of log-neural-cdes on the UCI archive (id 495), saved as `.npy`. Inputs are
(n, 49920, 6): three accelerometer axes, BVP, EDA and temperature at 64 Hz. Targets are (n, 390) heart rates. There are
1,020 training, 106 validation and 106 test windows.
